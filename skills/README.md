# Skills

This folder will hold the LLM "Skills" (each with its own `SKILL.md`) that
drive the agent's domain-specific analysis capabilities — e.g.
`sector-thematic-analysis`, `stock-analysis`, `etf-analysis`,
`macro-context-analysis`, `risk-analysis`.

**Not implemented yet.** Skills are in scope for **Fase 3** of the project
(see `docs/architecture.md`, section 8). Fase 1 only reserves this folder in
the repository structure so later phases have a stable location to add to.
